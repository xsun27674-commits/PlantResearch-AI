# Windows 绘图局部修复

适用于已经能启动、读取 Excel 的现有桌面安装，不需要重新安装。

1. 下载 `fix/categorical-plots` 分支的 ZIP 并完整解压（不要直接在 ZIP 内运行）。
2. 关闭 PlantResearch AI 的启动器窗口，确保其后端已退出。
3. 双击解压目录中的 `Repair-Charts.cmd`，确认更新。
4. 从原桌面快捷方式启动，重新上传 Excel，选择箱线图或柱状图，X 选择“处理组”，Y 选择“荧光焦点数”。

修复脚本只替换 `%LOCALAPPDATA%\PlantResearchAI\app\backend\app.py`，不下载或重装依赖，不改实验数据、API 设置或 Python。旧文件备份到 `chart-backups\<唯一编号>\app\backend\app.py`；写入失败自动回滚。手工回退时先关闭启动器，将该备份文件复制回原位置。

现有桌面安装前端是静态构建，因此局部脚本不替换前端：旧页面“箱线图使用 X 数值列”的说明已过时，实际支持 X 分类、Y 数值。新构建页面会展示中文缺失值明细；局部修复后的 PNG 底部也会显示删除行数（英文），完整中文策略和统计随参数保存到本地任务数据库。若使用源码运行，更新分支后照原流程构建前端即可，不必重装软件。

处理规则：
- 箱线图分类 X + 数值 Y：每组显示 Y 分布；数值 X 保留原有单列箱线图（忽略 Y）。
- 柱状图：按 X 分组计算 Y 均值；按出现顺序显示前 50 组。
- 散点图：两轴必须为数值列，文本列会得到中文提示。
- 仅删除当前图所需列中缺失或无穷值的行，空白分组标签也删除，不填补，不修改原始数据。其他列缺失不影响当前图。
- 相关性热图保留原功能，按每对数值列的有效成对观测计算，不填补。

## 验证

自动化测试覆盖中文分类、36×7 Excel、分组均值及分布、逐列缺失计数、不兼容列中文提示、无有效数据、原有 PDF/导出/助手/启动检查。

Linux 验证：`python -m pytest backend -q`；前端 `npx tsc --noEmit` 与 `npm run build`。
Windows 修复脚本需在 Windows 现有安装上人工验证；Linux 不声称已经验证 Windows GUI 或中文字体渲染。
